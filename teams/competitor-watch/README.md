# Competitor Watch

A two-bot intelligence desk that filters public pricing, positioning, product, and launch changes into decisions.

## Members

- **Watcher — Competitive Researcher:** owns dated public evidence and material-change detection.
- **Prism — Strategy Analyst:** owns interpretation, confidence, and the response decision.

## Included skills

- **Material Change Detection:** records meaningful changes and ignores cosmetic noise.
- **Competitive Decision Brief:** recommends watch, investigate, respond, or ignore.

Google Sheets is optional for a dated change log. This package never contains credentials or private competitive data.
